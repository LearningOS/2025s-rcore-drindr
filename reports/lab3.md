# 问答题
1. 不是，p2的stride溢出变为4，小于p2的stride，则还是会执行p2
2. stride每个时间片加BIG_STRIDE/2，执行过一轮后，则最小的可能stride为1，最大的为BIG_STRIDE/2，此时会优先再调度较小的stride，则两个任务之间stride的差距会减小，从而STRIDE_MAX - STRIDE_MIN <= BIG_STRIDE/2。
3. 令BIG_STRIDE = 255，则可知任意两个任务之间的stride差距小于等于128，想象将u8首尾接成环，于是当stride区间横跨0的时候有[STRIDE_MAX，255]接上[0，STRIDE_MIN]（STRIDE_MIN + (128 - STRIDE_MAX) < 128的时候)，于是哪怕stride溢出，各任务的优先级仍能正常工作
