# 问答题
1. 10位reserved，26位物理内存表号ppn[2]，9位物理内存表号[1]，9位物理内存表号[0]，1位D代表对应虚拟页表是否被修改过，1位A代表对应虚拟页表是否被访问过，1位G暂未提及，1位U代表对应虚拟页表允许在user特权级下被访问，X/W/R各占1位分别代表可取指/写/读，1位V代表可用
2.
  1. StoreFault, StorePageFault, LoadFault, LoadPageFault
  2. satp寄存器ppn字段会变为内核栈的ppn，并且刷新TLB
  3. 对于较大的程序段代码，Lazy策略可以有效防止一次性载入带来的过大的内存消耗
  4. 10G连续虚拟页表大约要20MB页表空间
  5. 捕获缺页时trap，查询是否非法访问的页表是否在.text段或磁盘中，如果存在则将其载入，再退出trap
  6. 页面失效时PTE上表现在代表V的位为0，代表不可用
3. 双页表与单页表
  1. 每次特权级变化时
  2. 通过页表项的U字段限制用户访问内核页面，通过将非本程序的页表V字段标记为不可用
  3. 单页表可以复用前两级页表，从而减少页表的内存开支，在小内存情况下有优势
  4. 双页表实现下，特权级状态更换的时候需要更换页表。单页表操作系统通过PTE中的U字段可以实现约束，无需考虑程序非法访问内核，只需在程序切换时切换即可，如果存在虚拟页表冲突，则可以在冲突时进行替换。
